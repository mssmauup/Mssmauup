मानव सेवा संस्था, जनपद मऊ — मुफ्त वेबसाइट पैकेज

फाइलें:
- index.html : पूरी responsive हिंदी वेबसाइट (एक ही फाइल में)

मोबाइल से लाइव करने का आसान तरीका (GitHub Pages):
1. GitHub पर मुफ्त खाता बनाएं/लॉगिन करें: https://github.com/
2. नया repository बनाएं, नाम उदाहरण के लिए manav-seva-sanstha रखें।
3. Public repository चुनें।
4. Add file > Upload files पर जाएँ और index.html अपलोड करें, फिर Commit changes करें।
5. Repository Settings > Pages में जाएँ।
6. Build and deployment में Deploy from a branch चुनें।
7. Branch: main और folder: /(root) चुनकर Save करें।
8. कुछ मिनट बाद GitHub Pages पेज पर दिखाई गई URL खोलें। यह आम तौर पर https://USERNAME.github.io/REPOSITORY/ के रूप में होगी।

महत्वपूर्ण संपादन:
- अभी सदस्यता फॉर्म ईमेल ऐप खोलने का प्रयास करता है, लेकिन संस्था का आधिकारिक ईमेल जोड़े बिना आवेदन स्वतः प्राप्त नहीं होगा।
- वास्तविक ऑनलाइन आवेदन जमा करने के लिए Google Forms बनाकर वेबसाइट के फॉर्म/बटन से जोड़ें: https://forms.google.com/
- वेबसाइट में वास्तविक कार्यक्रमों की फोटो, पूरा कार्यालय पता, संस्था का आधिकारिक ईमेल, पंजीकरण संख्या और अधिकृत पदाधिकारियों की जानकारी जोड़ें।
- नमूना गतिविधि कार्ड वास्तविक उपलब्धियों का दावा नहीं करते; उन्हें वास्तविक सामग्री से बदलें।
- फोन नंबर वर्तमान बातचीत में पहले साझा किए गए नंबरों के अनुसार रखे गए हैं; प्रकाशित करने से पहले सत्यापित करें।
- अपना .org/.in डोमेन वैकल्पिक है और आमतौर पर सालाना शुल्क लेता है। GitHub Pages का मुफ्त URL इस्तेमाल करने पर डोमेन खर्च नहीं होगा।
